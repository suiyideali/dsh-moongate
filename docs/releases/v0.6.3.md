# dsh-moongate v0.6.3

First release cut through the reviewed pull-request flow.

## Process

- `main` is protected: pull request + review from `@mochazZZ` (superagent) + `test` CI are required before merge.
- `.github/workflows/release.yml` creates the `v<version>` tag and GitHub Release after the release PR merges.
- `v0.6.2` and earlier were published directly; from `v0.6.3` on, every release is reviewed before tagging.

## Approval view

- Overview is collapsed by default; the timeline is the first thing you see.
- "Needs attention" banner and filter aggregate rejected and escalated records.
- Rows with a retained snapshot show "已保留改动快照 · 可撤销", keeping the undo path next to the decision.

## Metadata

- GitHub About no longer names the upstream package; topics are limited to `dsh-plugin`, `deepseek-harness`, `approval` and `security`.
- Upstream attribution and the `moongate` name explanation remain in the README Credits section.

## Install

```sh
dsh plugin --profile desktop add github:suiyideali/dsh-moongate
```

Then add the `auto-approve` permission preset as described in the README.
