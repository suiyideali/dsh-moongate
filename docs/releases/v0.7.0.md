# dsh-moongate v0.7.0

This release rolls up the roadmap work since v0.6.3 and fixes the permission-preset setup path that made the `auto-approve` preset missing for Desktop users.

## Fix: permission preset not selectable

- One-click **初始化权限预设 / Configure permission preset** now writes the **currently running profile** instead of hardcoding `profiles/web`. It resolves `DSH_PROFILE_DIR`/`DSH_PROFILE` first, then detects the profile directory from the Desktop host's argv (Desktop does not inject those env vars).
- Desktop users no longer need to edit YAML by hand: install → **审批 → 设置 → 初始化权限预设 → 一键配置权限预设** → restart DSH. The `自动审批（Flash）` preset then appears in the session permission dropdown.
- The setup card shows the target profile; install docs now include this step.
- Added a smoke regression test that verifies the preset is written to the active profile and never to `profiles/web`.

## Since v0.6.3

- **Shadow mode**: observe which requests would have been auto-allowed; observation is read-only and all candidates still go to a human.
- **Inline rule editing**, **per-project statistics**, **English UI**, and opt-in **semantic reuse**.
- **Command-aware learning** for safe bash intents, real-argument semantic comparison, and grouped Shadow rule suggestions.
- **Onboarding + safer learning defaults**: self-learning on by default (3 cumulative SAFE / 1 session), first-run banner, collapsible settings, merged learning card.
- **Read-only fast path + project trust**, with hardened path/symlink/argument handling.
- **P0 stop-loss observation**: `guard-candidate` events record repeated operations, session totals, and edited file counts without changing any decision.
- Settings controls use real switches, calmer button geometry, and improved dark-mode contrast.

## Install / upgrade

```text
github:suiyideali/dsh-moongate
```

After installing or updating, open **Approval → Settings → Permission preset**, click **Configure permission preset**, then restart DSH. Existing data in `~/.dsh/auto-approve/` is reused.

## Notes

- The `auto-approve` preset must be added to the profile patch layer; DSH freezes the preset table at composition time, so a plugin cannot register it at runtime.
- Do not enable upstream `dsh-approval-gate` and `dsh-moongate` at the same time.
