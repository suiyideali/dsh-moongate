# dsh-moongate v0.7.2

Stops self-learning from graduating signatures that are too coarse to be safe.

## Signature width gate

Self-learning (and automatic graduation) could graduate signatures like `bash|danger-full-access|~/*` — one rule for the whole home directory. Because allow rules are matched **before** the hard-risk categories (credentials, deletion, system paths), such a rule silently bypasses the human gate for an entire directory tree.

- New `signatureTooBroad()` check rejects any signature whose directory part is shallower than two levels (`~/*`, `/*`, `/tmp/*`) or sits in a sensitive root: `~/.ssh`, `~/.aws`, `~/.gnupg`, `~/.kube`, `~/.config`, `~/.dsh`, `~/.password-store`, `~/.local/share/keyrings`, `~/Library`, `/etc`, `/private/etc`, `/usr`, `/bin`, `/sbin`, `/Library`, `/System`, `/Applications`, `/opt`, `/var/db`, `/var/log`, `/private/var/db`, `/private/var/log`, `/boot`, `/proc`, `/sys`, `/var/root`, and any home directory that is not the current user's.
- Paths are normalized before the check: `~` is expanded, `..` and `//` are collapsed, and existing directories go through `realpath` (which also resolves case and symlinks, e.g. `/etc` → `/private/etc`). Without this, `/tmp/../etc/*`, `//etc/ssh/*` and `~/.SSH/*` all slipped past the list while still graduating a rule that auto-allows.
- Applied to both paths: `recordSelfObservation()` (Flash SAFE graduation) and `recordSignatureApproval()` (human-confirmed graduation).
- Rejections are audited as `SELFLEARN-SKIP` / `GRADUATE-SKIP ... 签名不可学习`, so you can see what was skipped and why.
- Home-level hidden directories (`~/.<name>`) are rejected outright as `hidden-dir`: `~/.docker/*.json`, `~/.cargo/*.toml`, `~/.gem/*`, `~/.android/*`, `~/.terraform.d/*.json` and friends all hold registry tokens or device keys, and listing every one of them would age badly. Deeper hidden segments (`~/proj/.cache/...`) stay learnable.
- Depth is counted with `~` or `/` as the root: `~/*` and `/*` are rejected, while `~/<project>/*.txt` and `/tmp/<project>/*.txt` (two segments) stay learnable. macOS temp space under `/var/folders/...` is deliberately not treated as sensitive.
- Rejections are de-duplicated by signature and reason, so a busy broad signature does not flood the audit log.

## Data note

Existing rules are **not** deleted by this change. If you already have a broad self-learned rule, disable it in **审批 → 设置 → 规则库**; the gate only prevents new ones. In the author's own 7-day run, `~/*` had 0 subsequent hits and `~/.dsh/profiles/*` had 1 — both had been disabled before this release.

The regression tests (`scripts/smoke.mjs`) assert that `~/xxx.txt` (depth) and `~/.dsh/profiles/x.txt` (sensitive) do not graduate after three SAFE verdicts, that `~/<project>/file.txt` still does, and unit-test the gate directly with `..`, `//`, case, a symlink to `/etc`, home-level dot-dirs and the expanded list, and drive `recordSignatureApproval()` end to end to assert `GRADUATE-SKIP` with no rule created.

## Upgrade

Update the plugin and **restart dsh web** — the check lives in the host module, so it only takes effect after a restart. No configuration change is required.
