# dsh-moongate v0.7.1

Fixes the UI language default and makes it explicit.

## UI language

- The plugin UI is now **Chinese by default**, regardless of the browser/OS language.
- Added **审批 → 设置 → 界面语言 / Approval → Settings → Interface language** with:
  - **中文 / Chinese** (default)
  - **English**
  - **跟随系统 / Follow system** — previous auto behavior
- Switching reloads the page so all labels apply consistently.
- English currently covers the main views; parts of Settings remain Chinese and will be filled in incrementally.

## Why

Earlier the plugin followed `navigator.language` automatically. Users whose browser reported `en-US` saw an English UI even though they never chose English. That was surprising and is now opt-in.

## Upgrade

Update the plugin, refresh the page, then choose the language in **审批 → 设置 → 界面语言**. The default is Chinese; no action is required if Chinese is desired.
